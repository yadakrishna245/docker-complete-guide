# 🤝 Contributing to Docker Complete Guide

Thanks for your interest in contributing! This project aims to be the most comprehensive Docker guide on GitHub.

## How to Contribute

### 🐛 Report Issues
- Found an error in a command? Open an issue.
- Something unclear? Let us know.

### 📝 Suggest Improvements
- Missing a Docker topic? Create an issue with the suggestion.
- Want to add an example? Submit a PR.

### 🔧 Submit a Pull Request

1. **Fork** this repository
2. **Clone** your fork:
   ```bash
   git clone https://github.com/YOUR-USERNAME/docker-complete-guide.git
   ```
3. **Create a branch:**
   ```bash
   git checkout -b feature/your-improvement
   ```
4. **Make your changes**
5. **Commit:**
   ```bash
   git commit -m "Add: description of what you added"
   ```
6. **Push:**
   ```bash
   git push origin feature/your-improvement
   ```
7. **Open a Pull Request** against `main`

## Guidelines

- Keep commands and examples tested and working
- Use clear, concise explanations
- Follow the existing formatting style
- Add examples for any new commands
- One topic per PR (keep it focused)
